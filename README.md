# Physics

A place to learn physics by building small simulations and experiments with code.
The project currently uses Python and Pygame, with SDL and OpenGL as possible
future tools.

## What you'll find here

- `gravity.py` - a simple Pygame simulation of a ball falling under gravity.

This is a learning project and will grow as new physics concepts and
visualizations are added.

## Getting started

You need Python and Pygame installed. From the project directory, install
Pygame if needed and run the simulation:

```bash
python -m pip install pygame
python gravity.py
```

The simulation opens in a window. Close the window to quit.

## Learning goals

- Explore physics concepts through interactive visual experiments.
- Build an understanding of motion, forces, and other topics by implementing
  them in code.
- Experiment with tools such as Pygame, and potentially SDL or OpenGL in the
  future.
